# 경희대학교 이과대학 전공 소개 앱

고등학교 후배들에게 경희대학교 이과대학의 학과별 특징과 대표 커리큘럼을 소개하기 위한 정적 웹 앱입니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 앱을 확인할 수 있습니다.

## 구성

- `index.html`: 앱의 화면 구조와 공식 출처 링크
- `styles.css`: 경희대 컬러를 활용한 반응형 UI 스타일
- `script.js`: 학과 선택, 상세 소개 렌더링, 랜덤 추천 기능
